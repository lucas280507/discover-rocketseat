# 🚀 Projeto Discover - Rocketseat

Projeto desenvolvido durante o curso **Discover** da [Rocketseat](https://www.rocketseat.com.br/), com o objetivo de aprender os fundamentos do desenvolvimento web.

## 📋 Sobre o Projeto

Uma landing page pessoal (portfólio) construída do zero utilizando HTML, CSS e JavaScript, aplicando os conceitos aprendidos ao longo do curso.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica
- **CSS3** — Estilização, Flexbox, Grid e responsividade
- **JavaScript** — Interatividade e manipulação do DOM
- **Git & GitHub** — Versionamento de código

## ✨ Funcionalidades

- ✅ Layout responsivo (mobile, tablet e desktop)
- ✅ Alternância de tema claro/escuro (Light/Dark Mode)
- ✅ Navegação suave entre seções
- ✅ Animações e transições CSS
- ✅ Barras de progresso animadas nas habilidades

## 🎨 Layout

O projeto possui dois temas:

- 🌙 **Dark Mode** (padrão)
- ☀️ **Light Mode**

## 📁 Estrutura de Arquivos

```
├── index.html   # Estrutura da página
├── style.css    # Estilos e responsividade
├── script.js    # Interatividade (tema, scroll, animações)
└── README.md    # Documentação do projeto
```

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/lucas280507/discover-rocketseat.git
```

2. Abra o arquivo `index.html` no navegador.
