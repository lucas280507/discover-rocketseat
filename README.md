# 🚀 Social Tree | Discover - Rocketseat

Projeto desenvolvido durante o curso **Discover** da [Rocketseat](https://www.rocketseat.com.br/), com o objetivo de aprender os fundamentos do desenvolvimento web.

## 📋 Sobre o Projeto

Uma página de links pessoais (Social Tree) construída do zero utilizando HTML, CSS e JavaScript, aplicando os conceitos aprendidos ao longo do curso.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica
- **CSS3** — Estilização, responsividade e variáveis CSS
- **JavaScript** — Interatividade (Dark/Light mode)
- **Git & GitHub** — Versionamento de código

## ✨ Funcionalidades

- ✅ Layout responsivo (mobile e desktop)
- ✅ Alternância de tema claro/escuro (Light/Dark Mode)
- ✅ Links para redes sociais
- ✅ Design moderno com glassmorphism

## 📁 Estrutura de Arquivos

```
├── index.html   # Estrutura da página
├── style.css    # Estilos e responsividade
├── script.js    # Toggle de tema (Light/Dark)
└── README.md    # Documentação do projeto
```

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/lucas280507/discover-rocketseat.git
```

2. Abra o arquivo `index.html` no navegador.
